# CampusConnect

CampusConnect is a responsive Campus Event Management and Registration Portal created for the CA1 problem-statement project.

## Features

- Browse upcoming college events
- Search by title, venue, or category
- Filter events by category
- Register students for events with a name and university email
- Live seat availability and over-registration prevention
- View and cancel registrations
- Organizer view for adding events and restoring sample data
- Responsive layout for desktop and mobile
- Browser `localStorage` persistence

## Technology

HTML, CSS, and vanilla JavaScript. No build step or external backend is required.

## Run locally

Open `index.html` in a browser. For the best local experience, use VS Code Live Server or another static file server.

## Deployment
This is a static site and is ready for Netlify. Use the repository root as the publish directory and leave the build command empty. The included `netlify.toml` contains the same settings for repeatable deployment.
